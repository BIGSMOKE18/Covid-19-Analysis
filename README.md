# 🦠 COVID-19 Data Analysis Dashboard

A complete data analysis and visualization project exploring the global impact of COVID-19.
This project includes **Python-based data preprocessing**, **exploratory data analysis**, and a fully designed **Power BI interactive dashboard** showing trends in cases, deaths, and demographics across continents and countries.

---

## 📌 Features

* 🌍 Global COVID-19 analysis
* 📈 Time-series trends of cases & deaths
* 🗺️ Continent-wise and country-wise breakdown
* 👤 Median age impact analysis
* 🧹 Cleaned & transformed dataset
* 📊 Power BI dashboard + Jupyter Notebook EDA

## 🧹 Data Preprocessing Steps

The dataset was cleaned and prepared using Python:

* Loaded raw COVID-19 global dataset
* Filled/handled missing values
* Converted date fields & normalized formats
* Grouped countries into continents
* Created measures for deaths, new cases & age averages
* Generated time-based summaries for Power BI visuals

## 📌 Key Insights from the Analysis

✔ The **United States, India, and Mexico** showed the highest death tolls.
✔ **Asia and North America** contributed the majority of global COVID-19 cases.
✔ Countries with **higher median age** often faced more severe case outcomes.
✔ Global death curves show strong waves during 2020–2021, especially in the US.
